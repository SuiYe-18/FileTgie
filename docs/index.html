Features

Small by design, safe by default

Each command performs a single, clearly bounded operation. Results are clear and expected; there are no surprise side effects.

Lightweight

A single compact executable with no runtime, no package manager and no configuration file.

Pure C, standard library only

Built from C standard library calls and platform-native APIs; no third-party dependency anywhere in the source tree.

Read-only safe

Inspection never modifies, deletes or moves user files. Normal writes are limited to its own filetgie.log; explicit update and the bundled updater only upgrade FileTgie itself, and optional reminder creates or removes one FileTgie-owned task.

Four switchable languages

Interface messages switch between cn, en, ja and ru with --lang; unknown codes warn and fall back to cn.

Cross-platform

src/port.c isolates the Windows wide-character Win32 API from POSIX; the rest of the code is platform-independent.

LGPL-3.0-or-later

Free to run, study, modify and redistribute; static and dynamic linking obligations are documented in LICENSE and COPYING.

Quick start

Usage and examples

FileTgie [--lang cn|en|ja|ru] [--exclude <glob>] [--exclude-ext <ext>] <command> [args...]
Count files and folders in a folder
FileTgie count D:\Photos
Sum all text-file lines in a codebase, English UI
FileTgie --lang en linesdir ./src
Find log files larger than 50 MB, largest first
FileTgie findlarge D:\app\logs 50
Search file contents for a text snippet and report line numbers
FileTgie findcontent ./src "TODO"
Verify two files are byte-for-byte identical
FileTgie compare a.bin b.bin
Show capacity, used and free space of every drive
FileTgie disk
  • Binary units (1024): B → KB → MB → GB step by 1024 (1 KB = 1024 B, 1 MB = 1024 KB); size, stat and du also print exact byte counts.
  • Language option aliases: --lang also accepts -lang, -l, and the equals form --lang=en / -l=ja; the code is case-insensitive and may appear before or after the command.
  • Exclusions: --exclude <glob> and --exclude-ext <ext> may be repeated; they apply only to traversal commands, not to commands that take an explicit single file such as lines or hash.
  • Run with no arguments or help to print the full command table (exit code 0).
  • Updates: checkupdate is read-only; update manually checks GitHub and the website before a silent Windows overwrite. reminder on defaults to a 1-minute read-only check, reminder on every 5 sets a 5-minute interval, reminder status reports the task, and reminder off deletes it. One notification appears for each newly discovered version.
Optional companions

Pair FileTgie with independent tools you already like

FileTgie does not download, call, bundle or require any companion below. Install them separately; let each tool do the job it does best, and use FileTgie for exact counts, line totals, size, hashes and directory comparison.

fd

fd finds candidate files by name quickly; pass a candidate path to FileTgie for exact size, line count or hash. The "file-finding twin" works without being embedded in FTG.

fd project

ripgrep (rg)

rg searches file contents at high speed; FileTgie gives exact text-line totals, byte size and integrity checks instead of replacing your search engine.

ripgrep project

fzf

Use fzf as an interactive fuzzy picker over a file list; once you choose, hand the selected path to FileTgie for a stable read-only report.

fzf project

bat

bat previews a file with line numbers and syntax highlighting; FileTgie reports the exact total line count, exact bytes and checksum.

bat project

eza

eza gives a modern directory listing or tree view; FileTgie counts files/folders, sums directory size and compares two directories with exact grouped numbers.

eza project

dust / duf

dust and duf visualize disk use; FileTgie reports exact free space, drive capacity, oversized files and byte totals from the command line.

dust project
Interface languages

Switch the UI with one flag

All prompts, errors and help strings ship in four language packs inside the binary; no external locale files are needed.

ru
Russian
  • Examples: FileTgie --lang en count D:\docs, FileTgie -lang ja lines ./a.txt, FileTgie -l ru disk.
  • An unrecognized language code prints a localized warning, falls back to cn, and the program keeps running.
  • langs lists the available language codes at runtime.
Get FileTgie

Portable package or build from source

Windows portable package

The portable package contains FileTgie.exe, FileTgieUpdater.exe, README, User Manual, LICENSE and COPYING. It writes no registry keys and nothing outside the folder; unzip and run, delete the folder to uninstall. The only file written next to the executable is its own filetgie.log.

Windows installer and overwrite upgrade

The installer registers App Paths and PATH under Program Files. It detects an installed copy, App Paths registration, or leftover files after a non-official deletion, and keeps the overwrite option checked by default. On overwrite, previous program files move to a disabled .old backup folder; the registry, PATH and shortcuts keep pointing only to the new root-folder files. The bundled updater checks GitHub and the website before launching a silent overwrite install.

Linux — build from source

v0.4.0 supplies Linux-compatible source code; run make on a Linux host and start with ./FileTgie --lang en help. Inspection commands need no installer, administrator rights or network; checkupdate uses curl for GitHub. The last verified x86_64 glibc prebuilt tarball remains in the v0.3.0 Release; musl/Alpine is not guaranteed.

make
