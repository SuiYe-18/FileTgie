# FileTgie Logo 使用说明

## 标志构成
- **FTG 字母组合**：F / T / G 三个等粗方块笔画咬合；G 的圆弧即放大镜圆环（带右下短柄），F 顶笔右端为文件页折角。一个图形同时表达「文件 + 查找 + 统计」。
- **字标**：FileTgie（F、T 大写，其余小写，拼写不可改动），几何无衬线。

## 配色（单色，无渐变）
| 角色 | 色值 | 用途 |
|---|---|---|
| 墨色（图标/文字） | `#1A1A1A` | 浅色背景上的标准黑标 |
| 反白 | `#FFFFFF` | 黑色/深色背景上的反白 |
| 背景黑 | `#000000` | 反白版底色 |

标准黑标与反白版互为正负形，黑白单色下均可辨认。

## 文件清单
| 文件 | 内容 | 使用场景 |
|---|---|---|
| `logo_1x1_black.png` | 标准黑标，1:1（图形在上、字标在下） | 白底/浅色背景、头像、文档 |
| `logo_1x1_white.png` | 反白版，1:1 | 黑底/深色背景 |
| `logo_wide_black.png` | 标准黑标横版（图形左、字标右，3:1） | 网站页眉、名片、横幅 |
| `logo_wide_white.png` | 反白横版（3:1） | 深色页眉/横幅 |
| `icon.png` | 透明底黑色图形标（无字标） | 浅色背景的 App/图标 |
| `icon_white.png` | 透明底白色图形标 | 深色背景的 App/图标 |
| `icon.ico` | 多尺寸图标（16/24/32/48/64/128/256） | FileTgie.exe、快捷方式、安装包 |

## 规范
- 安全区：标志四周留白不小于 FTG 组合高度的 1/3，不被其他元素侵入。
- 最小尺寸：完整组合标不小于 24px；纯图形图标不小于 16px。
- 禁止：改色、加渐变/投影/发光/3D、拉伸变形、更换字标拼写、在图标上叠加文字。
- 安装脚本 `installer\installer.iss` 读取本目录 `icon.ico`，文件已就位。
